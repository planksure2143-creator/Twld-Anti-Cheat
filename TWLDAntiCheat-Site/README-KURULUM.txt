TWLDAntiCheat web sitesi paketi
===============================

DOSYALAR
- index.html: Ana sayfa
- assets/style.css: Tasarım ve stiller
- assets/script.js: Küçük sayfa işlevleri
- downloads/: İndir butonunun hedeflediği klasör

ÖNEMLİ: GERÇEK PLUGIN JAR'I EKLENMEDİ
Bu paket web sitesi tasarımıdır; gerçek TWLDAntiCheat plugin JAR dosyası bu sohbette sağlanmadığı için sahte/çalışmayan bir JAR üretmedim.

İNDİR BUTONUNU ÇALIŞTIRMA
1. Gerçek ve derlenmiş plugin dosyanı şu isimle kaydet:
   TWLDAntiCheat-Paper-1.21.11.jar
2. Bu JAR dosyasını web sitesi klasöründeki downloads klasörüne koy.
3. Siteyi bir web sunucusuna yükle. Örnek: GitHub Pages, Netlify veya kendi hostingin.
4. Destek bölümündeki Discord bağlantısını kendi davet linkinle değiştir.

GOOGLE SITES HAKKINDA
Bu paket normal HTML/CSS/JS sitesidir; Google Sites içine bu dosyaları ZIP olarak doğrudan yükleyip tam site şeklinde çalıştıramazsın. Tam tasarımı yayınlamak için HTML dosyalarını barındırabilen bir hizmet kullan. Google Sites kullanacaksan, yayınlanmış sitenin bağlantısını veya desteklenen bir gömme seçeneğini kullanabilirsin.

PLUGIN'I MINECRAFT SUNUCUSUNA KOYMA
1. JAR dosyasını indir.
2. Paper sunucunun ana klasöründeki plugins klasörüne koy.
3. Sunucuyu yeniden başlat.
4. Konsolda eklentinin hatasız yüklendiğini kontrol et.
5. Eklenti gerçekten config oluşturuyorsa oluşan dosyaları incele.

Discord bağlantısı index.html içinde https://discord.com/ olarak ayarlı. Kendi destek davet linkinle değiştir.


DESTEK ASİSTANI
Destek bölümünde kullanıcılar sorunlarını yazabilir. Şimdiki sürüm, sık sorulan sorulara göre hazır çözümler sunan bir sohbet arayüzüdür. Gerçek ChatGPT/AI yanıtları için güvenli bir sunucu tarafı API bağlantısı gerekir; API anahtarını index.html veya JavaScript içine koyma.
